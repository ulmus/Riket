# Expertiser

Varje expertis ger +1 på relevanta aktiviteter och öppnar upp specialförmågor. Aktiviteter som kräver expertisen ger -3 om du försöker utan den. Förmågor som kräver expertis beskrivs i [[Förmågor#Expertisförmågor]].

## Läkare

- **Bonus på aktiviteter:** Smidighet + Analys för Akutvård i fält. Sinnen + Analys för diagnosticering och behandling.
- **Kräver expertisen:** Kirurgi (Smidighet + Analys), Lägga förband under eld (Smidighet + Strid).
- **Förmågor som kräver expertisen:** [[Förmågor#Fältsteril]], [[Förmågor#Snabb-triage]].

## Apotekare

- **Bonus på aktiviteter:** Analys + Analys för att identifiera, dosera eller framställa läkemedel och enkla antidoter.
- **Kräver expertisen:** Aktiv vård/medicin (Analys + Analys) när det handlar om doser och blandningar.
- **Förmågor som kräver expertisen:** [[Förmågor#Fältapotek]], [[Förmågor#Exakt-dos]].

## Radiotekniker

- **Bonus på aktiviteter:** Smidighet + Analys när du riggar radio/antenn eller stabiliserar förbindelse.
- **Kräver expertisen:** Bygga/rigga radio (Smidighet + Analys), stabilisera långdistanslänk under tidspress.
- **Förmågor som kräver expertisen:** [[Förmågor#Störningsbuffer]], [[Förmågor#Fältjustering]].

## Telegrafist

- **Bonus på aktiviteter:** Sinnen + Närvaro eller Sinnen + Analys när du lyssnar i brus/störningar (morse, signalspaning).
- **Kräver expertisen:** Läsa morse i brus (Sinnen + Närvaro/Analys), avlyssna trafiksplits under tidspress.
- **Förmågor som kräver expertisen:** [[Förmågor#Rensat-brus]], [[Förmågor#Signalmetadata]].

## Kryptograf

- **Bonus på aktiviteter:** Analys + Analys vid dekryptering och kodanalys.
- **Kräver expertisen:** Bryta komplex kryptering (Analys + Analys), sätta upp säkra kodsystem i fält.
- **Förmågor som kräver expertisen:** [[Förmågor#Kodspur]], [[Förmågor#Extra-segment]].

## Förfalskare

- **Bonus på aktiviteter:** Smidighet + Analys för förfalskningar (pass, stämplar, patina).
- **Kräver expertisen:** Förfalska identitetshandlingar som klarar detaljkontroller (Smidighet + Analys).
- **Förmågor som kräver expertisen:** [[Förmågor#Förberedd-kontroll]], [[Förmågor#Patinerat-verk]].

## Låssmed

- **Bonus på aktiviteter:** Smidighet + Analys för att dyrka eller bypassa lås och enkla larm.
- **Kräver expertisen:** Dyrka säkerhetsklassade lås (Smidighet + Analys), tyst öppning under tidspress.
- **Förmågor som kräver expertisen:** [[Förmågor#Tyst-bypass]], [[Förmågor#Effektiv-assist]].

## Sappör

- **Bonus på aktiviteter:** Analys + Analys när du laddar eller riggar spräng (riktverkan, säkringar).
- **Kräver expertisen:** Ladda sprängämne för kontrollerad riktverkan (Analys + Analys).
- **Förmågor som kräver expertisen:** [[Förmågor#Skyddad-zon]], [[Förmågor#Diskret-laddning]].

## Mekaniker

- **Bonus på aktiviteter:** Smidighet + Analys för fältreparation av fordon eller maskin.
- **Kräver expertisen:** Reparera fordon under jakt eller strid (Smidighet + Analys).
- **Förmågor som kräver expertisen:** [[Förmågor#Verktygspool]], [[Förmågor#Extra-funktion]].

## Elektriker

- **Bonus på aktiviteter:** Analys + Analys för sensorer, larm och enkla kretsar.
- **Kräver expertisen:** Koppla förbi larm (Smidighet + Analys) och säkra kanal för intrång.
- **Förmågor som kräver expertisen:** [[Förmågor#Maskerad-sensor]], [[Förmågor#Spårfri-bypass]].

## Maskör

- **Bonus på aktiviteter:** List + Närvaro för förklädnad, cover story och kroppsspråk i infiltration.
- **Kräver expertisen:** Förklädnad & uppträdande vid skarpa kontroller (List + Närvaro).
- **Förmågor som kräver expertisen:** [[Förmågor#Förberett-teamstöd]], [[Förmågor#Djupare-cover]].

## Förhörsledare

- **Bonus på aktiviteter:** List + Närvaro vid taktiska förhör (rapportbyggande, frågeteknik).
- **Kräver expertisen:** Förhöra taktiskt (List + Närvaro) i känsliga eller farliga situationer.
- **Förmågor som kräver expertisen:** [[Förmågor#Styrt-tempo]], [[Förmågor#Dubbel-verifiering]].

## Officer

- **Bonus på aktiviteter:** Strid + Närvaro när du leder i pågående strid (ordrar, elddisciplin).
- **Kräver expertisen:** Leda under press (Närvaro + Strid) i samordnad strid eller reträtt.
- **Förmågor som kräver expertisen:** [[Förmågor#Elddisciplin]], [[Förmågor#Initieringsorder]].

## Chaufför

- **Bonus på aktiviteter:** Smidighet + Smidighet i biljakt och undanmanöver.
- **Kräver expertisen:** Biljakt – körning (Smidighet + Smidighet) i tät trafik.
- **Förmågor som kräver expertisen:** [[Förmågor#Delad-linje]], [[Förmågor#Pressad-växel]].

## Underrättelseanalytiker

- **Bonus på aktiviteter:** Analys + Analys eller Sinnen + Analys när du bygger lägesbild och källvärdering.
- **Kräver expertisen:** Undersöka brottsplats (Sinnen + Analys) på metodisk nivå, bygga sammanhängande lägesbild under tidspress.
- **Förmågor som kräver expertisen:** [[Förmågor#Brief]], [[Förmågor#Förutse-nästa-drag]].

## Säkerhetsofficer

- **Bonus på aktiviteter:** Sinnen + Analys för att upptäcka intrång, läckor och fällor.
- **Kräver expertisen:** Lokalisera sensorer (Sinnen + Analys) och upptäcka intrångsförsök i realtid.
- **Förmågor som kräver expertisen:** [[Förmågor#Fördröjd-angripare]], [[Förmågor#Modusidentifiering]].
