## Vårdtyper

Det finns tre olika sätt att vårda skador och effekter, var och en med sin egen attributkombination:

### Medicin (Analys + Sinnen)

Medicinsk behandling handlar om att diagnostisera, medicinera och övervaka patienten. Används för:
- Stoppa blödningar
- Stabilisera döende patienter
- Behandla förgiftning och sjukdom
- Lindra effekter som illamående, yrsel, feber, och inre skador
- Administrera motgift eller smärtstillande

**Expertis Medicin:** Ger +1 tärning och tillgång till avancerade behandlingar.

### Kirurgi (Analys + Smidighet)

Kirurgisk behandling innebär invasiva ingrepp för att reparera skador. Används för:
- Operera ut kulor och splitter
- Sy ihop djupa sår och artärer
- Reparera brutna ben (sätta och gipsa)
- Behandla inre blödningar
- Amputera skadade lemmar (nödfallsåtgärd)

Kirurgi kräver normalt operationssal eller åtminstone steril miljö och kirurgiska instrument. Fältkirurgi är möjlig men har **+1 svårighet**.

**Expertis Kirurgi:** Ger +1 tärning och tillgång till avancerade operationer.

### Psykologi (Analys + Samspel)

Psykologisk behandling hjälper patienter hantera stress och trauma. Används för:
- Lindra stress (ta bort Stress-poäng)
- Behandla hallucinationer och förvirring
- Hjälpa patienten bearbeta trauma
- Stödja återhämtning från chock

**Expertis Psykologi:** Ger +1 tärning och kan behandla djupare psykologiska skador.

## Behandling av skador

Att behandla skador handlar om att stoppa blödningar, stabilisera patienten och lindra akuta symptom.

- **Handling:** Kräver en Huvudhandling i strid, eller några minuters arbete utanför strid.
- **Utrustning:** +1 tärning med första-hjälpen-kit; +2 tärningar med läkarväska.

### Grundläggande behandling

| Åtgärd | Vårdtyp | Svårighet | Effekt |
|--------|---------|-----------|--------|
| Stoppa blödning | Medicin | 0 | Alla nivåer av blödning från en skada upphör |
| Stabilisera Döende | Medicin | 0 | Patienten behöver inte slå Överlevnadsslag |
| Ge motgift | Medicin | 0 | Stoppar gifteffekter (kräver rätt motgift) |
| Lugna patient | Psykologi | 0 | Ta bort 1 Stress per framgång |

### Behandla kritiska effekter

Kritiska träffar (se [[Kritiska träffar]]) kräver specifik behandling beroende på effektens typ. Effekter markerade "tills behandlad" kräver ett lyckat vårdslag för att upphöra.

| Effekttyp | Vårdtyp | Svårighet | Exempel från tabellerna |
|-----------|---------|-----------|-------------------------|
| Blödning (alla nivåer) | Medicin | 0 | Skärsår, artärblödning, kraftig blödning |
| Stukning/stukade leder | Medicin | 0 | Stukat finger, stukad led |
| Yrsel/svaghet/illamående | Medicin | 0 | Vindpinad, yrsel, svaghet |
| Hjärnskakning | Medicin | 0 | Hjärnskakning (väcker inte, men stabiliserar) |
| Brutna ben/leder | Kirurgi | 0 | Brutet ben, bruten arm, krossad hand |
| Genomstungna kroppsdelar | Kirurgi | 0 | Genomstungen hand/fot, genomskjuten hand |
| Djupa sår med Döende | Kirurgi | +1 | Stucken i magen, djupt brösthugg |
| Genomstungen lunga | Kirurgi | +1 | Genomstungen lunga, lungskott |
| Artärskador | Kirurgi | +1 | Artärblödning, artärträff |
| Inbäddat splitter/kula | Kirurgi | +1 | Kula fastnad, djupt splitter |
| Svåra brännskador | Kirurgi | +1 | Svåra brännskador, tredje gradens brännskada |
| Krossade revben/intern skada | Kirurgi | +1 | Krossade revben, intern skada |
| Organskador (lever/njure/lunga) | Kirurgi | +2 | Lever-/njursvikt, njurskott, lungskada |
| Hjärt-/ryggradsskador | Kirurgi | +2 | Genomstucket hjärta, ryggradsskott |
| Gifteffekter (fysiska) | Medicin | 0 | Magkramper, muskelspasmer, kramper |
| Hallucinationer | Medicin | +1 | Hallucinationer (Gift #6) |
| Andnöd (gift) | Medicin | +1 | Andnöd (kräver motgift) |
| Strålsjuka (mild) | Medicin | 0 | Svaghet, feber, hudutslag |
| Strålsjuka (svår) | Medicin | +2 | Benmärgsskada, lungskada, njursvikt |
| Inre blödning (strålning) | Kirurgi | +2 | Inre blödning (kräver sjukhusvård) |

**Lyckad behandling:** Effekten upphör eller ersätts med mildare konsekvens (SL avgör). Effekter med **Läketid** kräver även tid för att läka helt.

**Misslyckad behandling:** Du kan inte försöka igen på samma patient i samma scen, om inte förutsättningarna förbättras avsevärt (t.ex. tillgång till bättre utrustning eller flytt till sjukhus).

### Speciella krav

Vissa kritiska effekter anger specifika krav i tabellerna:

| Krav i tabellen | Betydelse |
|-----------------|-----------|
| "tills behandlad" | Kräver lyckat vårdslag för att upphöra |
| "Kräver sjukhusvård" | Kan inte behandlas i fält, kräver sjukhus |
| "Kräver motgift" | Medicin-slag räcker inte, kräver rätt motgift |
| "Kräver hjärt-lungräddning" | Stabilisering kräver HLR (Medicin, +1 svårighet) |
| "Måste opereras ut" | Kräver Kirurgi för att ta bort främmande föremål |
| **Läketid:** X veckor/månader | Tiden för full återhämtning efter behandling |
| **Permanent** | Läker aldrig helt, se Permanenta skador |


## Läkning

Kroppspoäng (KP) återhämtas genom vila och vård. Hur snabbt beror på omständigheterna.

### KP-återhämtning

| Vårdnivå | KP per dag |
|----------|------------|
| Ingen vila (aktiv) | 0 KP |
| Vila (lugnt, ingen ansträngning) | 1 KP |
| Fältvård/hemvård | 2 KP |
| Sjukhus | 3 KP |

### Kritiska skador

Effekter från **kritiska träffar** (se [[Kritiska träffar]]) läker inte automatiskt med KP. Varje kritisk effekt har sin egen läketid, ofta 1T12 dagar eller veckor beroende på allvarlighet.

- **Lätta effekter** (yrsel, blåmärken, stukning): Försvinner efter 1T12 dagar.
- **Måttliga effekter** (brutna ben, djupa sår): 1T12 veckor med vård.
- **Svåra effekter** (organskador, amputationer): 1T12 månader, eller permanent.

Kirurgisk vård på sjukhus kan halvera läketiden för icke-permanenta skador (SL avgör).

### Permanenta skador

Vissa kritiska träffar ger **permanenta** effekter (t.ex. amputationer, kronisk smärta, nedsatt syn). Dessa läker inte bort men kan ibland lindras med hjälpmedel:

- **Proteser och ortoser:** Minskar rörelserelaterade avdrag.
- **Glasögon/hörapparater:** Minskar sinnesrelaterade avdrag.
- **Rehabilitering:** Kan minska vissa permanenta avdrag med –1 efter 1T12 månaders träning.

Se [[Kritiska träffar]] för specifika effekter och deras permanenta konsekvenser.
